I built a distance meter using a SparkFun VL53L4CD time-of-flight sensor and a RedBoard Plus. A 16×2 LCD shows the live distance in millimeters, and three LEDs indicate how close the object is.

I needed to measure distance for another project, so I built this prototype to see how well the sensor worked. The LCD gives me the exact reading, and the LEDs let me see the distance range at a glance.
